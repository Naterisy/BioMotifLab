DNA Motif Discovery and Background Calibration

Abstract
DNA motif discovery can confuse differences in background composition with conserved binding patterns. This study develops BioMotifLab, an inspectable platform for fixed-width, double-stranded motif discovery, probability-matrix analysis, conditional permutation testing, and interactive reporting. A smoothed one-occurrence-per-sequence expectation-maximization model is evaluated with uniform, pooled, and strand-symmetric sequence-specific backgrounds. Sequence-level estimates can be shrunk toward pooled frequencies, while a coverage-based heuristic ranks initial candidate words. These are evaluated as project-level design choices within an independent implementation, without claiming that local background modeling is new.
Controlled experiments use independent training and test sequences under two composition settings, three substitution rates, and five data-generation seeds. Under extreme GC heterogeneity and a substitution probability of 0.30, adaptive nucleotide-localization F1 is 0.913 ± 0.022, compared with 0.441 ± 0.107 for the pooled model. The adaptive model does not outperform the uniform model in the high-noise homogeneous setting. Ablations do not demonstrate additional localization-F1 gains from shrinkage or enriched initialization. A post hoc four-motif panel supports a composition-dependent effect but retains substantial variation and failure cases. Fixed-model testing permutes nucleotides within held-out sequences and adjusts sequence-level comparisons. A real CRP case study contains eighteen sequences of 105 nucleotides; the uniform and adaptive configurations each produce three adjusted-significance events across repeated splits, without establishing consistent superiority.
The software includes a command-line interface, a functional Streamlit interface, sequence logos, exportable results, automated tests, and raw experimental records. The findings support a limited conclusion about background granularity under controlled conditions. Broader biological effectiveness, competitiveness with external discovery tools, and clinical utility remain unestablished.

Keywords: DNA motif discovery; sequence background; expectation maximization; permutation test; reproducible computational biology

# Chapter 1 Introduction
## 1.1 Biological motivation
Transcription factors recognize sequence patterns in DNA and contribute to the regulation of gene expression. Their preferences are rarely captured by a single perfectly conserved string. Some positions tolerate several nucleotides, whereas others strongly favor one base. A DNA motif summarizes this structured variation. Finding a shared motif in a collection of regulatory sequences can therefore suggest candidate binding preferences and locations for subsequent investigation. Such a prediction is a hypothesis about sequence compatibility, rather than direct evidence that a protein binds that location in a living cell. Accessibility, cooperative interactions, experimental conditions, and other factors remain outside a sequence-only model.
Motif discovery combines a statistical estimation problem with a search problem. The locations of the relevant segments are unknown, so the algorithm must estimate both the pattern and its placement. Many alternative placements can explain part of a small dataset, and a locally stable solution need not correspond to the intended biological signal. Background composition creates an additional difficulty. A GC-rich segment may receive a high score against a uniform nucleotide distribution even when it is ordinary within its own sequence. When a dataset combines sequences with very different compositions, a single pooled background can also conceal important differences between sequences.
BioMotifLab investigates a narrow, testable question: does representing the background at the sequence level improve discovery when the sequences have heterogeneous GC composition? The software implements an inspectable probabilistic model, matched internal baselines, independent test-sequence scoring, and a functional analysis interface. This scope is relevant to computational biology and to the interpretation of sequence models used in biomedical artificial intelligence. However, the project contains no clinical cohort, disease endpoint, or diagnostic evaluation. Its practical value is educational and exploratory: users can inspect how a background assumption changes a motif and examine the evidence supporting that result.
## 1.2 Existing approaches and research scope
MEME established a widely used probabilistic approach to motif discovery based on expectation maximization, and the MEME Suite provides complementary tools for discovery, scanning, enrichment, and interpretation [1-2]. Accordingly, neither the use of a position-specific matrix nor the combination of motif discovery and visualization constitutes a new fundamental algorithm in this project. BioMotifLab instead provides a small implementation in which background estimation, initialization, optimization, and evaluation can be examined separately. External MEME and STREME executables were not run in the reported experiments; the internal baselines must not be mistaken for those mature tools.
Reference motif databases and sequence datasets serve different purposes. JASPAR distributes curated transcription-factor binding profiles that can support known-motif scanning and comparison [3]. A frequency matrix is not a collection of genomic sequences with independently verified binding coordinates. This distinction matters because agreement with a reference matrix, accurate localization of a planted sequence, and discrimination between positive and negative sequences answer different questions. The evaluation in this study keeps these tasks separate rather than presenting a single ambiguous accuracy number.
The implemented discovery model considers one fixed-width motif and assumes exactly one occurrence in every training sequence, the one-occurrence-per-sequence or OOPS setting. Both strands are searched, and coordinates are reported on the original input sequence. Windows containing ambiguous bases are excluded. The system does not perform read alignment, peak calling, de novo genome assembly, or functional annotation of clinical variants. Restricting the scope makes the statistical assumptions explicit and permits direct tests of implementation correctness, while also limiting the strength of biological conclusions.
## 1.3 Candidate designs and selection
Three candidate designs were considered. The first uses a transparent probabilistic discovery model with alternative backgrounds, background-aware seed selection, and held-out significance assessment. It has a clear biological motivation because composition can confound regulatory-sequence analysis. Its innovation potential lies in a carefully delimited method design and empirical comparison, not in claiming that background modeling itself is new. Its computation and implementation requirements are moderate, and its components can be removed or changed in controlled experiments.
The second design combines multiple motif widths with resampling-based stability ranking. It could address uncertainty about width and identify patterns that repeatedly emerge from subsets of the data. Its principal costs are repeated searches, an expanded candidate space, and additional model-selection questions. A stable pattern can still reflect a stable compositional artifact, so stability alone would not replace background modeling or independent testing. The third design uses a convolutional sequence model and attribution-based interpretation. It offers greater representational flexibility, but requires a stronger data justification, more training decisions, and additional checks of whether the explanation corresponds to the learned predictive mechanism.
The first design was selected after considering biological relevance, contribution boundaries, computational cost, implementation difficulty, and experimental verifiability. It permits an interpretable comparison within a limited computing budget. The project-level hypothesis is that a strand-symmetric, sequence-specific background can reduce composition-related confusion, while shrinkage may stabilize its estimates and a coverage-based heuristic may supply useful initial candidates. These are hypotheses to test separately. A working interface demonstrates engineering completeness, but it does not establish algorithmic novelty or effectiveness.
# Chapter 2 Models and Statistical Foundations
## 2.1 Probability matrices and scanning scores
Let the DNA alphabet be A, C, G, and T, and let the motif width be w. A position probability matrix theta has w rows and four columns. The entry theta(j,b) gives the probability of nucleotide b at position j, and every row sums to one. A position frequency matrix stores counts before normalization. Pseudocounts avoid assigning zero probability to a nucleotide that was not observed in a finite sample. The model assumes independence between positions conditional on the motif. This assumption makes the model interpretable and computationally convenient, but does not represent dependencies between neighboring bases.
A motif probability becomes a discriminative scanning score only after it is compared with an appropriate background. For sequence i, let q_i(b) denote the background probability of base b. The score of an oriented window y is the sum of position-specific log probability ratios:
[[EQ_SCORE]]
The implementation uses natural logarithms, so the score is measured in nats. A high value means that the window is better explained by the motif than by the specified background. It does not directly express the probability of functional binding. The same window can receive different scores under different backgrounds, and a change in background can alter which window is selected. These effects are part of the model definition, rather than an optional cosmetic adjustment.
Sequence logos summarize the probability matrix using base frequencies and information content [4]. Under a uniform reference distribution, the information content at position j is two bits minus the entropy of that row. Each nucleotide receives a fraction of the column height proportional to its probability. Logo information is expressed in bits, whereas the scanning scores here use natural logarithms. A highly structured logo can nevertheless arise from overfitting random data. The interface therefore displays the matrix and predicted locations together with the scope of any independent statistical assessment.
## 2.2 Latent positions and smoothed EM updates
For sequence x_i of length L_i, a latent state identifies a valid start position and a strand. The implementation enumerates every unambiguous forward window and its reverse complement. A uniform prior is assigned to the available states in that sequence. With a fixed background, the posterior responsibility of a window is proportional to the exponential of its log-ratio score. Responsibilities are normalized within each sequence, so each training sequence contributes a total weight of one to the fitted motif.
[[EQ_RESP]]
The update accumulates expected nucleotide counts at each motif position and adds 0.25 to each base count. The denominator is N+1, where N is the number of training sequences. This smoothing prevents zero-probability entries and corresponds to a regularized update; the reported unpenalized objective is not asserted to increase monotonically under every update. The implementation stops when the maximum absolute change in the probability matrix falls below 10^-6 or when the iteration limit is reached. No claim of a tested monotonic-likelihood guarantee is made.
[[EQ_UPDATE]]
For each initialization, the final solution is evaluated by the sum, across sequences, of the log-sum-exp of its window scores minus the logarithm of the number of candidate states. This quantity omits a fixed background constant and is used to choose among starts within the same background specification. Comparing its raw magnitude across different background models would not by itself establish superior discovery. The optimization remains nonconvex, and different initial candidates can produce different local solutions. Sampling-based motif search is also a well-established research direction [5], but the default enriched initialization in this implementation is deterministic. Random seeds control generated datasets, the explicit random-initialization ablation, and permutation tests; they do not make the default search stochastic.
## 2.3 Conditional significance and multiple testing
Statistical significance requires a defined null hypothesis and a defined unit of testing. The implemented test conditions on the nucleotide counts of each held-out sequence. Known nucleotides are randomly permuted within the sequence, while the positions of N characters remain fixed. The null hypothesis is that arrangements with these fixed counts are exchangeable. This procedure preserves mononucleotide composition, but not dinucleotide counts or longer-range sequence structure. It is therefore more limited than a general model of genomic background.
The statistic is the largest scanning score across all valid positions and both strands of a sequence. Each permuted sequence is scanned in exactly the same manner. Recomputing the maximum includes the within-sequence search in the null distribution, instead of evaluating only the selected window as though its position had been specified in advance. The fitted motif remains fixed throughout this evaluation. For B permutations and K null statistics at least as large as the observed statistic, the empirical p-value is:
[[EQ_PVALUE]]
The added one in both numerator and denominator avoids reporting zero significance probabilities from a finite permutation sample [6]. With B=199, the smallest reportable value is 0.005. The software additionally reports Benjamini-Hochberg adjusted values across the tested sequences for a single fixed model [7]. Their usual false-discovery-rate interpretation requires appropriate assumptions about dependence. Homologous or otherwise correlated input sequences may violate simple independence assumptions. The adjustment also does not cover a user repeatedly trying widths, methods, or matrices and retaining whichever result looks most significant.
# Chapter 3 Requirements and System Design
## 3.1 Analysis workflow and input conventions
The intended workflow starts with a FASTA collection, proceeds through validation and discovery, and ends with inspectable results and exportable records. Users choose the motif width, background method, initialization budget, iteration limit, and relevant statistical settings. An independent validation collection can be supplied for fixed-model scanning and permutation assessment. Training positions are descriptive outputs of the fitted model; validation statistics are kept separate so that model selection on the discovery data is not disguised as independent confirmation.
The parser accepts common IUPAC DNA symbols, converts letters to uppercase, and maps ambiguous symbols to N. Invalid characters, empty records, missing FASTA headers, and empty datasets produce explicit errors. A sequence that is shorter than the selected width or contains no fully known candidate window cannot be analyzed under the current model. The parser preserves header information when requested, while computational results also use sequence indices. Duplicate headers are not claimed to be rejected. Coordinates use zero-based, half-open intervals on the original sequence, including predictions on the reverse strand.
The command-line and interactive interfaces call the same computational functions. This allows a visual result to be traced to the same logic used by the experiment scripts. The interface supports actual file upload, algorithm selection, backend execution, matrix and logo inspection, method comparison, and report download. It is not a static illustration. The command-line route is better suited to scripted experiments, whereas the interface helps users inspect individual datasets and understand the effect of parameter choices.
## 3.2 Modules and data flow
The software separates input handling, core probability calculations, significance assessment, synthetic generation, experimentation, and presentation. The input module manages sequence normalization and FASTA errors. The core module constructs windows, estimates backgrounds, ranks candidates, fits matrices, and scans sequences. The statistics module performs conditional permutations and adjusts the resulting sequence-level p-values. Synthetic generation supplies controlled data with explicit truth coordinates. The experiment scripts combine these components under recorded settings and write both detailed and summarized results.
[[FIG_ARCH]]
This separation supports fault localization. A reverse-strand coordinate error can be tested directly in the core module. A disagreement between a table and its underlying measurements can be investigated in the aggregation or plotting code. The presentation layer does not maintain a second implementation of motif discovery. Structured results include the matrix, consensus, positions, scores, parameters, and warnings about interpretation. Exporting these fields is more useful for scientific review than exporting a logo alone, because the model and its provenance remain accessible.
## 3.3 Reproducibility and data stewardship
A reproducible analysis must specify more than a random seed. The repository records input sources, file hashes, dependency versions, algorithm parameters, dataset construction, and the definition of each metric. The default synthetic consensus is fixed independently of sampled backgrounds. Training and testing sequences are generated with separate seeds, and comparisons share the same datasets. Raw results remain available so that tables and figures can be recalculated without estimating values from plotted curves.
Public availability does not automatically authorize unrestricted redistribution. The project source code has its own license, which does not relicense third-party biological data or software. The CRP example is obtained through a download script with source and integrity information rather than being silently incorporated into the project license. The JASPAR profile has separate attribution and version information. The public manuscript excludes student identity fields, while a separate submission copy contains the provided cover information. User-uploaded sequences and credentials are not part of the published repository.
# Chapter 4 Background-Aware Discovery
## 4.1 Strand-symmetric sequence backgrounds
Let n_i,b be the observed count of nucleotide b in sequence i, and let comp(b) be its complement. Strand-symmetric counts average each nucleotide count with that of its complement. This construction gives A and T equal background probabilities, and likewise C and G, so the two orientations are evaluated against a consistent compositional reference. Let n_i denote the number of known nucleotides. The pooled background adds 0.5 to each aggregated count; the adaptive background adds both the pooled contribution and this small smoothing term:
[[EQ_BACKGROUND]]
The parameter tau is a pooled-background pseudocount strength, with a default of 40. Small values retain more sequence-specific composition, whereas large values move the estimates toward the pooled distribution. Shorter sequences receive relatively stronger pooled influence. The additional 0.5 term avoids zero probabilities even when a nucleotide is absent. The method name adaptive refers to the fact that the background varies across sequences; it does not imply that tau is learned by an optimal data-driven procedure.
Latent-site EM was already studied in early motif research [8]. More elaborate background models and sequence context have been investigated by BioProspector and subsequent work [9-11]. More directly, Gibbs Recursive Sampler used sequence-specific background characterization through Bayesian segmentation, and NestedMICA used mosaic backgrounds to represent heterogeneous composition [12-13]. These precedents make a broad claim of inventing local or adaptive backgrounds untenable. BioMotifLab therefore does not claim to invent background correction, sequence-specific estimation, or sequence context. Its contribution is a transparent implementation and evaluation of one particular zero-order, strand-symmetric design within a complete reproducible workflow. The design can be criticized at the level of its assumptions and assessed through direct comparisons.
The biological motivation is that two sequences can have different typical compositions even when they share a motif. A pooled reference may treat an ordinary segment of one sequence as exceptional. A local reference can reduce this discrepancy, but it introduces its own estimation error. The motif itself contributes to the counts used to estimate the background, potentially attenuating its signal. This issue is especially relevant when sequences are short or the motif occupies a large fraction of their length. Shrinkage may control variability, but its benefit must be observed rather than assumed.
## 4.2 Candidate coverage and initialization
Candidate words are extracted from valid windows, with a word and its reverse complement represented by the same canonical form. Instead of counting every repeat equally, the heuristic records how many sequences contain the candidate at least once. For a word u, this observed coverage is O(u). Its approximate expected coverage under the selected backgrounds uses the number m_i of valid forward genomic starts before adding reverse complements, the background probability of the word, and an orientation multiplier of two for a nonpalindromic word or one for a palindrome.
[[EQ_SEED]]
The ranking statistic is a computational heuristic. Its Poisson-style expectation ignores dependence between overlapping windows, and the denominator is a stabilizing scale rather than a proof of a known sampling distribution. Consequently, the value is never interpreted as a p-value. Top-ranked candidates initialize matrices with probability 0.85 at the corresponding nucleotide and 0.05 at each alternative. The random-initialization ablation instead samples windows from randomly selected sequences. The k-mer baseline takes the highest-ranked candidate and uses its initialized matrix without EM refinement.
Changing the background also changes candidate ranking. The comparison between pooled and adaptive methods is therefore a comparison of complete configurations, not a strict single-factor intervention on the denominator of a score. An experiment that forces identical initial matrices across backgrounds has not been conducted. Removing shrinkage or replacing enriched seeds provides useful component evidence, but cannot resolve every interaction among initialization, optimization, and background estimation. This distinction prevents the observed gains from being attributed too precisely to one mechanism.
## 4.3 Held-out evaluation and leakage control
Training sequences determine the candidate set and fitted matrix. Testing that selected matrix on the same sequences using a fixed-matrix null distribution would ignore the selection step and could produce overoptimistic significance. The pipeline instead fits the matrix on the discovery collection and freezes it before testing another collection. The pooled training background is passed to scanning. The adaptive method still estimates the composition of each held-out sequence and shrinks it toward that frozen training reference. Within-sequence permutations preserve those counts, keeping the background consistent throughout a conditional test.
Separating files is not sufficient if the files contain identical, reverse-complement, near-duplicate, or homologous sequences. The interfaces reject exact sequence overlap, including reverse-complement equivalents, while broader homology requires appropriate preprocessing and study design. Repeatedly inspecting validation outputs to modify methods would also turn those outputs into tuning information. The reported sensitivity analyses are descriptive evaluations of prespecified parameter settings within the project, not an attempt to select the best setting separately for every test condition and present that collection as one universal method.
## 4.4 Algorithm and computational cost
The complete algorithm first validates sequences and encodes valid windows. It estimates the requested backgrounds, forms initial candidates, and fits one matrix for each permitted start. Each iteration normalizes window responsibilities and updates smoothed nucleotide probabilities. The best final objective selects the returned matrix. Discovery outputs include consensus and maximum-scoring positions. If a separate validation collection is supplied, the fixed matrix is scanned on it and compared with sequence-specific permutation distributions.
[[PSEUDO]]
Let M be the total number of candidate windows, w the motif width, R the number of starts, I the iteration limit, N the number of sequences, and U the number of distinct canonical words. The principal EM cost is O(R I M w), and encoded windows require approximately O(M w) memory. Candidate construction adds O(M w); constructing word count vectors adds O(U w); estimating expected coverage adds O(U N); and sorting candidates adds O(U log U). These terms matter when many distinct words occur, so reporting only the EM term would understate the full discovery cost. Conditional testing adds repeated scanning work proportional to the number of permutations. Increasing R addresses optimization coverage, whereas increasing B improves the resolution of statistical assessment; neither parameter substitutes for the other.
# Chapter 5 Implementation and Verification
## 5.1 Numerical and sequence correctness
Multiplying many small probabilities can underflow. Core computations therefore use logarithms and stable log-sum-exp normalization. Positive smoothing keeps valid scores finite. The maximum matrix-change tolerance and iteration limit provide explicit stopping rules. Parameter validation checks motif width, counts of starts and iterations, shrinkage strength, and the number of permutations before expensive work begins. Failure messages identify unsuitable inputs rather than silently removing records and returning results for an unexplained subset.
Reverse-complement handling combines a change in nucleotide identity with reversal of order. The returned interval must still identify the original sequence segment. Tests therefore use a nonpalindromic known motif at controlled positions and compare both orientations. A palindromic motif has an inherent orientation ambiguity, so a strand label cannot always be uniquely interpreted. Likewise, the localization metric used in the experiments evaluates genomic intervals rather than jointly requiring correct interval and strand; these are different accuracy definitions.
## 5.2 Interactive use and exports
The Streamlit interface accepts discovery and independent validation FASTA files. Users can select methods and adjust width, starts, iterations, shrinkage, seed, and permutation count. Computation produces real matrices, consensus sequences, positions, and logos. Method comparison uses the same uploaded sequences. The command-line interface provides equivalent core computation and saves structured results, a report, and a logo. Known-motif scanning and discovery are conceptually distinct tasks, as illustrated by the role of FIMO in the MEME ecosystem [14]; BioMotifLab implements a limited transparent scanning routine rather than all of FIMO's functionality.
The interface limits interactive workloads to reduce accidental long-running submissions. Such limits are operational safeguards, not statements about the algorithm's mathematical scalability. Results distinguish training descriptions from held-out statistical evidence. Under OOPS, the training model returns a preferred window even for a sequence that actually has no binding site. A user must not interpret that forced assignment as proof that the sequence contains a functional occurrence. Exported configuration and scope statements help preserve this distinction when results are shared.
## 5.3 Testing and reproducibility checks
Automated tests cover probability normalization, strand handling, strict input errors, monotonicity of adjusted p-values after ranking, nonzero empirical p-values, and recovery of strong planted signals. Interface and command-line tests exercise real calculation and parameter transmission. An additional native-browser check confirms that the application can execute the example analysis and expose result exports. These checks establish that important implementation paths operate as intended; they do not establish scientific superiority.
The project was also installed and tested in a clean environment. Experiment records were independently compared with their generated truth and rescored predictions. A test that invokes an online source check is separately identifiable, so skipping an optional network-dependent check is not represented as equivalent to verifying that source online. Exact test counts can evolve with maintenance and are recorded in the repository's verification report. The manuscript concentrates on the scientific protocol and the relationship between measurements and conclusions, rather than treating a passing test suite as a substitute for empirical evaluation.
# Chapter 6 Experiments and Critical Analysis
## 6.1 Datasets and evaluation protocol
The main synthetic experiment uses the consensus ACCTGCTGTA, generated once with a separate fixed seed of 1729. Each condition contains 30 training and 30 independently generated test sequences, each of length 80 nucleotides, with one planted occurrence of width 10 per sequence. Position and strand are sampled randomly. Each motif position changes to one of the other three bases with probability 0, 0.15, or 0.30. Background heterogeneity h is either zero or one, with sequence-specific GC probability 0.5 plus or minus 0.4h. Thus the heterogeneous setting deliberately uses GC probabilities of 0.1 and 0.9. It is a stress test of composition mismatch, not an estimate of typical promoter composition.
The five data-generation seeds are 11, 22, 33, 44, and 55; test seeds equal the corresponding training seeds plus 10000. All methods share datasets and fitted width. EM methods use six starts and at most 50 iterations. The main design contains 120 fits, and parameter, ablation, and scaling studies add 55 fits. Variation across repeats largely reflects backgrounds, positions, and realized substitutions, because default enriched initialization is deterministic. Only the random-initialization ablation introduces that particular source of optimization randomness.
For a predicted interval P and true planted interval T, nucleotide localization F1 is 2|P intersect T|/(|P|+|T|), averaged over test sequences. Exact-start accuracy is the fraction whose predicted start equals the planted start. These metrics ignore strand orientation and do not measure detection of motif absence. Values are summarized by the mean and sample standard deviation across five repeats. The raw file records individual runs, and detailed records preserve fitted matrices, predictions, and truth. No metrics are inferred from an attractive logo or generated without executing the analysis.
The real case study uses the official MEME CRP example containing 18 sequences of length 105, for a total of 1890 nucleotides. Each split uses 12 sequences for discovery and six for held-out assessment. The fitted width is 20, with eight starts, 60 maximum iterations, and 199 permutations. Header numbers were not verified as binding-site labels and are not used as truth. A downloaded JASPAR CTCF matrix, MA0139.1, is a separate reference-resource example; it is not the corresponding motif for bacterial CRP. This real-data exercise checks the workflow on authentic sequences but cannot establish labeled localization performance or biological efficacy.
## 6.2 Main comparison and noise dependence
All four configurations achieve perfect localization in the zero-substitution conditions. This result confirms that the implementation can recover an easy common pattern, but offers little discrimination between methods. At a substitution probability of 0.15 in homogeneous backgrounds, the EM configurations are close. Increasing noise to 0.30 reduces their performance substantially. The adaptive configuration reaches 0.339 plus or minus 0.113, slightly below the uniform model at 0.350 plus or minus 0.151. This counterexample is retained rather than omitted from the headline result.
[[TABLE_MAIN]]
Under heterogeneous composition and mutation probability 0.15, adaptive localization F1 is 0.993 plus or minus 0.016, compared with 0.947 plus or minus 0.018 for the pooled background. At mutation probability 0.30, the respective values are 0.913 plus or minus 0.022 and 0.441 plus or minus 0.107. These differences are consistent with a composition-related explanation within this controlled setting. However, the extreme background mixture and fixed consensus constrain the inference. They do not establish superiority across regulatory datasets, organisms, motif families, or biological assay types.
[[FIG_NOISE]]
The k-mer baseline is less stable when substitutions disrupt repeated exact words. EM can combine evidence from related windows, but its assignments may also reinforce a background pattern. These contrasting failure modes explain why a simple string-based baseline remains informative despite lower average performance. The plotted error bars describe observed repeat variability; they are not confidence intervals demonstrating significance of every pairwise difference. No retrospective choice of a favorable noise condition is substituted for the complete table.
## 6.3 Ablations and parameter sensitivity
Ablations use heterogeneous composition and mutation probability 0.15. The complete adaptive configuration achieves 0.993 plus or minus 0.016. Setting tau to zero gives 0.995 plus or minus 0.012, and random initialization gives 0.993 plus or minus 0.016. Therefore, the experiment does not show an additional localization benefit from the default shrinkage strength or from enriched initialization. Relative to the pooled configuration, the evidence is consistent with the importance of sequence-specific composition, but the initialization interaction prevents a fully isolated causal interpretation.
[[TABLE_ABLATION]]
For tau values of 5, 200, and 1000, localization F1 is respectively 0.995 plus or minus 0.012, 0.979 plus or minus 0.031, and 0.954 plus or minus 0.029. Increasing shrinkage moves the background toward the pooled distribution and reduces the benefit in this extreme heterogeneous setting. The default value 40 is a reproducible operating choice, not a demonstrated optimum. The slightly stronger result without shrinkage is a substantive negative finding for the proposed stabilization component and must remain visible in the assessment of contribution.
[[FIG_SENSITIVITY]]
Fitting widths of eight and twelve to true width-ten motifs gives F1 values of 0.828 plus or minus 0.064 and 0.873 plus or minus 0.034. The metric itself penalizes unequal interval lengths: even perfect containment cannot produce a Dice overlap of one when lengths differ. Thus this sensitivity study reflects both boundary selection and the definition of localization accuracy. A low overlap under a mismatched width does not necessarily mean that every biologically relevant nucleotide was missed. Conversely, selecting the best width after observing test truth would leak evaluation information.
## 6.4 Independent significance and the CRP case study
A separate experiment uses 40 independently generated test sequences per repeat, with 20 planted positives and 20 true negatives. Discovery still uses an independent positive training collection. The fixed model is assessed with 199 conditional permutations, and a sequence is called positive at p at most 0.05 or adjusted q at most 0.05. At the q threshold, adaptive classification F1 is 0.941 plus or minus 0.041 and recall is 0.890 plus or minus 0.074. The pooled-background values are 0.880 plus or minus 0.056 and 0.790 plus or minus 0.089.
[[TABLE_CLASSIFICATION]]
Both configurations have zero observed false positives at that adjusted threshold in this limited experiment. This does not establish a population false-positive rate of zero: there are only five repeats with 20 negative sequences each. Finite permutation resolution and multiple-testing adjustment also influence sensitivity. The results support a particular controlled discrimination task, while the null assumes exchangeable mononucleotide arrangements. Repeats or dinucleotide dependence in real regulatory sequences may make that null inadequate. Neither a p-value nor an adjusted value is a posterior probability that a predicted site has biological function.
[[TABLE_REAL]]
Across the five CRP splits, both uniform and adaptive models produce three held-out events with q at most 0.05; pooled and k-mer configurations produce none. The 30 testing events reuse some of the same 18 sequences across splits and are not 30 independent biological samples. Different splits and background settings produce different consensus sequences. The real case study therefore does not establish a stable advantage for the adaptive method. Its role is to demonstrate actual data acquisition, fitting, held-out scanning, and appropriately limited interpretation on a small public example.

## 6.6 Exploratory extension and validity threats
After the main results were inspected, an additional panel was run using four consensuses, three seeds, two background settings, and two methods, for 48 fits at mutation probability 0.30. The consensuses are ACGTCAGTCA, GCGCGGCCGC, ATATTAATAT, and TGACGTCAAG. They vary in composition and complexity. This extension is explicitly post hoc and exploratory, not a preregistered confirmatory test. Its purpose is to examine whether the initial conclusion depends too strongly on one consensus, while preserving both improvements and counterexamples.
Across twelve motif-by-seed combinations under heterogeneous backgrounds, the mean paired adaptive-minus-pooled F1 difference is 0.2233 with a sample standard deviation of 0.1437. Under homogeneous backgrounds, the corresponding difference is only 0.0103 plus or minus 0.0727, with four negative differences. For the GC-rich consensus in heterogeneous backgrounds, pooled and adaptive means are approximately 0.527 and 0.640, substantially below the strongest main-experiment result. For the AT-rich consensus in homogeneous backgrounds, adaptive performance is 0.430, below the pooled value of 0.467, and seed 303 produces severe failure for both configurations.
The extension provides additional support for a composition-dependent effect while showing that motif composition and complexity constrain its magnitude. It still covers only a handful of designed patterns and one small real dataset. The synthetic generator satisfies the model's independent-position and OOPS assumptions, making recovery easier than in collections with absent sites, multiple sites, spacing constraints, or correlated background structure. True regulatory datasets may also contain assay-specific biases that cannot be reproduced by changing GC frequency alone.
STREME offers a modern motif-discovery route that would be useful in a stronger external comparison [15]. The current internal baselines compare controlled configurations but do not establish competitiveness with mature software. Benchmark selection itself can substantially affect conclusions in motif discovery [16]. A stronger next study would include external executables under documented settings, additional labeled real datasets, multiple motif families, correlated background controls, and an untouched final evaluation set. More flexible deep-learning approaches also require their own sample-size and interpretation arguments [17]; adding network complexity would not automatically resolve the present weaknesses.
# Conclusions
BioMotifLab implements a complete path from validated DNA sequences to inspectable motif models, double-stranded scanning, conditional held-out tests, and interactive reports. The project provides source code, tests, configurations, raw measurements, figures, and explicit data provenance. Its scientific contribution is a bounded empirical investigation of background granularity within a reproducible teaching and exploration platform. Established EM, probability matrices, sequence logos, and multiple-testing procedures are credited rather than presented as original inventions.
The controlled results support sequence-specific background modeling under extreme between-sequence GC heterogeneity. They also show that the method can fail under weaker signals and homogeneous composition. The ablations do not establish additional localization-F1 gains from shrinkage or enriched seed selection, and the CRP case study does not show consistent superiority over a uniform background. These limitations are central to the result, because they identify which parts of the original hypothesis are supported and which remain unproven.
Future work should strengthen external baselines, biological ground truth, background realism, and separation between tuning and final testing. A fixed-initialization experiment would help isolate the effect of background scores from candidate ranking. Models allowing zero or multiple occurrences would broaden the practical scope. Until those evaluations are completed, the platform is suitable for education and exploratory regulatory-sequence analysis, with no validated clinical diagnostic claim.

Appendix A Reproduction Guide
The public repository is https://github.com/Naterisy/BioMotifLab. Create an isolated Python environment, install the project dependencies, and run the automated tests before reproducing the experiments. The dependency lock records the observed research environment; runtime and memory can differ across machines.
Acquire the real dataset with python scripts/download_data.py. The downloader records sources and verifies content hashes. Run python scripts/run_experiments.py for the main, ablation, sensitivity, classification, and CRP experiments. Run python scripts/plot_results.py to regenerate the principal figures from recorded results. The plotting script reads the default results directory.
The post hoc extension is reproduced with python scripts/run_motif_panel.py. Independent-process resource measurements are reproduced with python scripts/profile_resources.py. These analyses are separate from the 175 discovery fits in the original raw file and should not be silently combined into its run count.
The files results/config.json, raw.csv, and details.json preserve settings, discovery measurements, predictions, and planted truth. The files significance.csv and real.json preserve held-out assessments. The files motif_panel.csv and motif_panel.json contain the exploratory panel. The files environment.json and resources.csv distinguish cumulative experiment-process memory from fresh-process measurements.
Launch the local interface with streamlit run app.py. A complete command-line example is: biomotiflab data/example/train.fasta --test-fasta data/example/test.fasta --width 10 --method adaptive --starts 8 --iterations 60 --shrinkage 40 --seed 42 --shuffles 199 --out analysis/example. The command saves structured results, an analysis report, and a sequence logo.
Rerunning the default experiment scripts can replace the default result files. Preserve the reference results or work in a separate checkout when performing comparisons. Check dataset hashes and evaluation definitions before comparing numbers. Small floating-point differences can depend on numerical libraries; timing and resident-memory values are intrinsically environment dependent.
