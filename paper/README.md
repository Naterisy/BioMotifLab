# 课程论文

- `BioMotifLab课程论文.docx`：可编辑的公开研究版，未包含学生身份字段。
- `BioMotifLab课程论文.pdf`：25页固定排版版。
- `paper_source.txt`：正文可读源稿，中文汉字8921字（按U+4E00–U+9FFF计数，包含章节标题，不含摘要、参考文献、表格和附录）。其中`[[TABLE_*]]`和`[[FIG_*]]`为排版插入位置；对应图表读取`results/`实际实验记录。

完整论文含中英文摘要、目录、六章正文、结论、15条可核验参考文献、附录与AI辅助披露。没有声称收缩项或种子启发式已经取得独立精度增益，也没有声称优于外部MEME/STREME或具备临床验证。

排版依据与未获取官方Word模板的限制见`docs/fzu_format.md`。DOCX保留宋体/黑体样式；当前PDF通过bundled LibreOffice使用Songti SC/STHeiti代替本机缺少的Windows字体，已经渲染检查。目录页码与固定PDF一致，编辑DOCX后需要重新核对。

提交用带身份封面的副本独立保存，不属于此公开仓库。课程正式名称为用户确认的《医学人工智能导论》，项目按生物计算研究任务实施。
