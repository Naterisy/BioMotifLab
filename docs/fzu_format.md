# 福州大学论文格式核实记录

核实日期：2026-11-16。本文为课程项目论文，采用本科毕业论文的排版规范，不冒称已完成毕业论文行政流程。

官方来源：[福州大学先进制造与海洋学院《福州大学本科生毕业设计（论文）撰写规范》](https://xjzz.fzu.edu.cn/info/1083/3979.htm)，页面发布日期2022-12-29。全文可以通过浏览工具核实。另查官方历年工作通知，未找到可确认取代此规范的2026年校级新文本；不能据此断言其为当前唯一最新版本。学校允许学院细化要求，课程教师要求优先。

未获得可验证的官方Word模板。教务处历史下载链接已不可访问；检索到的GitHub Word/LaTeX模板明确标为非官方。本项目不复制这些模板，依据上述官方可核实条款自行排版。

实施规则：A4，上和左边距25mm，下和右20mm；中文正文宋体小四、固定20pt，首行缩进2字；章标题黑体小二、居中、另页；一级节标题黑体三号；图表题宋体五号；中文摘要独立一页，目标500–800汉字；英文摘要独立一页；目录列出章、节与页码；正文页码从第一章开始，前置部分独立罗马数字；参考文献按正文出现顺序和GB/T 7714—2015整理；参考文献正文五号、17pt；图题置下、表题置上，按章编号。官方表格无左右边线要求优先于通用文档样式。

封面使用简洁课程论文封面；因未获得校级统一封面原文件，不声称封面完全复刻官方。课程论文不附伪造签名、诚信承诺或指导教师审核。公开版本不包含学号、姓名等身份字段，提交副本单独保存。字体若运行环境缺少对应字体，必须在交付时说明实际替代与渲染状态。

适用性：官方毕业论文规范含8000字软件类正文等毕业环节要求；本任务课程要求为不少于5000汉字，正文力争8000汉字。并不将毕业任务书、翻译或答辩等要求擅自施加于课程提交。

最终渲染字体：DOCX保留宋体、黑体与Times New Roman样式名称；本机没有Windows SimSun/SimHei，PDF由bundled LibreOffice通过任务专用fontconfig使用系统Songti SC与STHeiti替代。替代字体已经逐页渲染检查；如教师要求严格Windows字体字形，可在安装正版宋体/黑体的Word环境打开DOCX再导出PDF。
