# 局限性、负结果与验收边界

以下限制依据本次代码与实际结果，不能在摘要、论文或展示中省略为“未来可优化”的空泛描述。

## 1. 创新证据只覆盖部分设计

本项目独立实现并检验了逐序列收缩背景和覆盖富集种子策略，但它们建立在既有EM、PWM与背景模型研究之上。没有证据支持“首次提出自适应背景”“原创EM”或“全面领先MEME”。外部MEME/STREME没有在此工程中实际运行，因此当前四算法结果都是本项目内实现的对照。

主实验支持在所设强GC异质性条件下使用逐序列背景。可是τ=0局部背景F1=0.994667，默认τ=40为0.992667；种子消融的随机起点亦得到0.992667。收缩本身及富集初始化的额外精度贡献尚未成立，不能为了创新叙事删掉消融结果。更强的后续检验应增加短序列、小样本、多种共识基序及相同固定起点下的背景对照。

## 2. 合成数据分布范围有限

默认共享一个固定随机共识基序，多个种子改变序列、位置和突变而不改变基序本身。因此主实验五次重复只估计该模型条件下的随机变化。后续追加了4个共识、3个种子、2种背景、2个算法的48次探索面板，保存全部结果，但设计发生在主结果查看之后，不是预注册确认，也不足以证明跨转录因子泛化。面板中的均质AT富集基序也出现adaptive(0.430)低于global(0.467)的失败。高异质性场景GC=0.1或0.9，是刻意设置的压力条件；它可能放大局部背景的收益。背景是IID，不含二核苷酸依赖、同聚物长串、转座重复或染色质状态。

均质高噪声（突变率0.30）时adaptive定位F1均值0.339333，低于uniform的0.350000，且各自标准差较大。该失败说明有限起点和短弱基序仍会受局部最优、偶然模式及背景估计波动影响。均值不同不自动意味着统计显著差异，本项目没有据五个种子作普遍优越性推断。

## 3. 模型的结构性限制

模型是固定宽度、无间隙、单一基序的双链OOPS，每条训练序列强制分配一个位点。它不能直接表达没有位点、多个位点、复合基序或间隔可变的结合结构。阴性序列也会得到一个最高分位置；是否显著应另外检验。代码只实现零阶背景，不声称已经实现一阶Markov或上下文依赖校正。

碱基计数包含潜在基序本身，局部背景估计因此可能吸收信号，尤其序列很短时。链对称约束减少参数，但无法表示真实链不对称。模糊碱基转N后排除窗口，可能导致覆盖减少；不能把其当作已观测碱基。

## 4. 显著性是有条件的序列级结论

置换保留每条序列的单碱基计数与N位置，假定有效碱基在零假设下可以交换。它破坏二核苷酸和更长依赖，故并非所有真实基因组背景下都能校准假阳性。取双链最大值已纳入同一序列的位置搜索，但没有校正用户反复选择多个PWM、宽度或算法产生的选择。

固定训练PWM后仅在独立留出序列检验；训练与检验包含相同序列会报错，仍不能自动识别同源、近重复或反向互补泄漏。独立性需由数据划分协议保证。BH值只针对同一模型的留出序列族；序列相关性可能影响其FDR解释。B=199时p的分辨率为0.005，少量置换的离散性限制检验力。

q≤0.05不是“该位点95%真实结合”，更不是实验或临床验证。序列级最大分数的显著性也不直接证明最高分坐标就是真实结合位置。

## 5. 真实CRP案例的证据很弱

CRP只有18条经选择的105nt序列，无完整基因组负对照。5次12/6随机划分反复使用同一批序列，不能当作30个独立生物样本。原文件标题数字没有被核实为统一坐标标签，故不使用；也不把外部算法预测当作真值。

在真实留出数据中，BH显著序列数adaptive与uniform均为平均0.6/6，global与kmer为0/6；uniform原始p≤0.05的数量反而较高。不能据此宣称真实数据上自适应方法全面优胜，更不能制造CRP定位F1。JASPAR的CTCF矩阵属于另一个物种/因子示例，不能作为CRP基序相似度的参照。

## 6. 指标与资源测量边界

定位F1是预测与真实区间的Dice重叠，不检查正负链方向；精确起点比例也不检查方向。只有合成数据能使用植入真值。有无基序分类另外使用独立阳性/阴性数据与p/q阈值，不能混称为定位性能。

运行时间是CPU主机上的墙钟时间，包含真实拟合开销，受调度与缓存影响。`environment.json`里的峰值RSS是整个实验进程累计高水位，不是各算法独立峰值，更不是内存复杂度证明。候选窗口显式存储，数据过大时会增加内存占用；界面限制输入体量，而CLI需要使用者评估规模。
